Chat, charge, and check: paid means proven.

Code and docs on GitHub

A seller and a buyer chat, the seller asks for payment in the thread, the buyer pays from the thread, and each phone shows “paid” only when it has checked the proof itself. Below are both phones, running now in your browser. Nothing to install and nothing to sign in to.

Ready

Press Play to watch one order from start to finish, or use the two phones yourself.

To try it by hand: type any PIN of six or more characters on each phone and press Start. Then send a message, or ask for 250 sats from the seller’s phone and pay it from the buyer’s.

What is real here, and what is simulated

Real

  • Each phone is the same Tab build that the repository produces, unchanged.
  • Messages are signed, end-to-end encrypted and checked on arrival (NIP-17, NIP-44).
  • Each phone talks to its wallet with real Nostr Wallet Connect requests (NIP-47).
  • “Paid” still needs proof: a preimage that hashes to the invoice, and the seller’s own wallet saying the invoice settled.
  • The buyer’s 10,000 sat daily limit is enforced by the wallet, not by the app.

Simulated, inside this page

  • The relay. It lives in this browser tab, so the two phones cannot be on different devices.
  • The two Lightning wallets, and the payment between them. No Lightning node is involved.
  • The money. No bitcoin exists here, not even test coins.
  • The keys and wallet links. The page makes new ones on every visit and fills them in for you.

The version with real Lightning payments runs on a private test network (regtest) with Bitcoin Core, two LND nodes and two Alby Hub wallets. It starts with one command from the repository, and the project’s tests run against it.

What the relay in the middle sees

Every event the simulated relay has accepted so far, newest first. It can see who a message is for and when it was sent. It cannot read any of them.

Run the real thing

Needs Linux or WSL 2, Node 24, pnpm and Docker.

git clone https://github.com/saintparish4/tab && cd tab
pnpm install
mkdir -p .stack && docker compose up --build -d

Then open http://localhost:8080/?demo=merchant and http://localhost:8080/?demo=customer in two windows. The README has the rest, including the tests and the threat model.

Built for the Dakar Bitcoin Hack by BTrust, November 2026. Regtest only, not audited. Do not connect a wallet that holds real funds.
